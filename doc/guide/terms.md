# 常见名词

| 名称 | 在 Tiller 中的意思 |
| --- | --- |
| PVE / Proxmox VE | 提供虚拟化能力和 API 的平台，Tiller 连接它来管理资源 |
| 节点 | 一台运行 PVE 的主机 |
| 数据中心 / 集群 | 多个资源与节点的管理层级；集群相关功能取决于实际组网 |
| 客户机 | 虚拟机和容器的统称 |
| VM / QEMU | 虚拟机，有自己的虚拟硬件和操作系统内核 |
| CT / LXC | 容器，与宿主机共享内核 |
| VMID | 客户机的数字 ID，执行操作时用它确认目标 |
| 存储 | PVE 配置的存储目标，可支持磁盘、ISO、模板或备份等内容 |
| 资源池 | 用于组织资源和授权的集合，不是存储池 |
| 快照 | 客户机在某个时间点的状态，用于回退；不能代替独立备份 |
| 备份 | 可用于恢复客户机的数据副本 |
| 认证域 / realm | 账号由哪个认证系统验证，例如 `pam`、`pve` 或 OpenID |
| TFA / 2FA | 密码之外的第二步验证 |
| Ticket | PVE 登录后发放的会话凭据，由浏览器 Cookie 携带 |
| ACL / 角色 | 在指定资源路径上授予用户或组的操作权限 |
| UPID | PVE 任务标识，用于查找某次操作的状态和日志 |
| Guest Agent | 运行在虚拟机中的辅助服务，可向 PVE 提供 IP 等信息 |
| Cloud-Init | 镜像首次启动时读取用户名、网络等初始化配置的机制 |
| HA | 高可用管理，用于根据集群条件调度受管资源 |
| SDN | 软件定义网络，集中管理虚拟网络相关配置 |
| PWA | 可添加到主屏幕的 Web 应用形态；管理 PVE 仍需网络 |
| SHA-256 指纹 | 用来核对并固定信任某张证书的摘要 |

遇到具体问题时，可以用顶部搜索查找对应词语，或返回[常见问题与排查](troubleshooting.md)。
