# 首次设置与登录

Tiller 使用独立的管理员账户。它与 PVE 的账号、密码和认证域无关。

## 首次打开

1. 打开 Tiller 地址，进入「设置管理员」。
2. 设置管理员用户名（3 到 40 位字母、数字、下划线、点或短横线）。
3. 设置至少 12 个字符的密码，并再次确认。
4. 点击「创建管理员」，进入实例管理，添加第一个 PVE。

只有首次启动、尚未设置账户时才显示创建入口；不会提供通用默认密码。当前版本是单管理员模式。

## 添加 PVE

在实例管理页点击「添加实例」，填写名称、PVE 地址和证书设置。认证方式默认为「账号密码」：输入 PVE 用户名、密码和认证域（Linux PAM 通常为 `pam`，PVE 内部账户为 `pve`），保存前会验证登录。也可直接填写 `root@pam` 这样的完整用户名。

也可以选择「API Token」，填写 Token ID 和 Secret。创建 Token 的位置是 PVE 的「数据中心 → 权限 → API Token」。已启用两步验证的 PVE 账户请使用 Token。

同一集群只添加一次，填写其中一个节点的地址即可。每个实例使用自己的账号密码或 Token。详细说明见[多实例连接](configuration.md#多实例连接)。

保存后点击「进入实例」。电脑侧边栏会按实例分别列出节点和客户机，相同 VMID 不会合并；点击资源直接进入对应 PVE 的详情页。之后打开 Tiller 会进入上次使用的实例，手机可在顶部切换实例。

## 后续登录与修改密码

再次打开时，输入你设置的 Tiller 管理员用户名和密码。无需逐个登录 PVE。

通过「管理员账户」可修改密码，需要提供当前密码。修改成功后，所有设备的登录会话和正在连接的控制台失效，必须使用新密码重新登录。

## 会话与退出

管理员会话最长有效 8 小时；服务重启后需要重新登录。退出 Tiller 会撤销当前浏览器会话，并关闭通过这个会话连接的控制台；其他独立登录的浏览器仍可使用。

共用设备使用完毕后，请在「管理员账户」或实例页账户菜单主动退出。不要只依赖关闭浏览器。
