# 首次登录

使用已有的 PVE 账号登录 Tiller。无需再注册一套 Tiller 账号，权限也沿用 PVE。

## 选择认证域

1. 打开 Tiller 地址，检查页面显示 Tiller 的登录表单。
2. 选择账号所属的认证域。Linux PAM 通常对应 `pam`，PVE 内部账号通常对应 `pve`；其他域由管理员配置。
3. 输入用户名与密码，点击登录。域选错时，即使密码正确也会失败。

如果选择的是 OpenID 域，页面会引导你跳转到身份提供方登录，完成后回到 Tiller。

## 完成两步验证

账号启用了两步验证时，密码通过后还需要第二步。页面会根据 PVE 返回的可用方式提供验证码、恢复码、安全密钥或其他已配置方式。

- **验证码（TOTP）**：使用认证器当前显示的验证码，手机时间应保持准确。
- **恢复码**：使用尚未消耗的恢复码。每个码只能使用一次。
- **安全密钥 / 通行密钥（WebAuthn）**：按浏览器和设备提示操作；需要 HTTPS，且访问域名要与 PVE 的 WebAuthn 设置兼容。

验证方式不可用时，不要反复尝试相同输入，先按[常见问题](troubleshooting.md)检查访问地址和账号配置。

## 登录后先检查

进入概览，确认节点名称、客户机数量和资源列表属于预期的 PVE。首次接入可以先打开一台已有客户机的概要，检查状态，再进行写操作。

桌面从左侧导航进入各页面；手机底部是「资源 / 存储 / 任务 / Shell」。更多说明见[导航与资源概览](../manual/navigation.md)。

## 会话与退出

Tiller 会在登录到期前尝试续签。长时间断网或续签失败时，页面会提示重新登录。

使用完毕后从「账户菜单 → 退出登录」退出。关闭浏览器与清理浏览器会话的行为可能因浏览器设置而异，共用设备请主动退出。

登录页会记住上次使用的用户名和认证域，方便下一次输入；不会把密码填回表单。
