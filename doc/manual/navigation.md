# 导航与资源概览

概览把节点、虚拟机和容器集中显示。先找到资源，再进入详情页执行操作，可以减少在不同节点间来回切换。

## 电脑上的入口

左侧主导航以两列排列，包含概览、数据中心、资源池、存储、任务和 Shell。下方选择器默认聚焦当前 PVE 实例，也可选择「全部实例」或进入实例管理。资源按节点展示，名称在前、VMID 在右，图标区分虚拟机和容器；模板、存储默认折叠，需要时展开。类型按钮可快速筛选虚拟机或容器，分组菜单保留按资源池、标签浏览的方式。

资源过滤框始终搜索全部实例，支持实例名、资源名称、VMID、节点和标签。点击其他实例的资源会完整切换连接，主导航及后续操作随之切换。展开状态会保存，每个实例的滚动位置在当前浏览器标签页内保留；进入资源详情时会展开并定位该资源。连接异常仅在对应分支提示，可点击重试。顶部搜索图标打开命令面板，底部提供外观与账户入口。

点击资源名称进入详情。详情页中的标签会按对象类型变化：虚拟机有硬件和 Cloud-Init，容器有资源、网络和 DNS，节点有网络、磁盘和系统设置等。

桌面端标签保持单行。空间不足时，右侧会显示左右箭头，点击即可滚动查看其余入口；切换标签或调整窗口大小后，当前标签会自动保持可见。

## 手机上的入口

顶部实例选择器用于切换 PVE，登录后默认打开上次使用的实例。底部悬浮导航提供「资源 / 存储 / 任务 / Shell」，搜索按钮打开命令面板。详情页的主要操作放在底部操作栏；较多的操作会收进菜单。

横向标签栏可以滑动。打开编辑表单后，先检查标题中的资源名称，保存前核对目标。账户菜单中可进入数据中心、外观与偏好，以及这份使用文档。

客户机列表上方的标签筛选保持单行，左右滑动可查看其余标签。点击标签可筛选对应客户机，再次点击取消；标签旁的数字表示客户机数量。

## 搜索与命令面板

点击搜索，或在电脑上按 `Ctrl + K` / `⌘ + K`。命令面板可用于搜索资源、跳转页面，以及执行当前可用的资源操作。

搜索结果中的操作会使用当前账号的权限。遇到删除、停止等确认窗口时，检查具体对象后再继续。

## 概览与数据中心的区别

| 入口 | 适合做什么 |
| --- | --- |
| 概览 / 资源 | 找节点和客户机，查看运行状态与资源使用 |
| 资源池 | 按管理员划分的资源集合浏览客户机 |
| 数据中心 | 管理集群级配置，如权限、存储定义、计划备份、HA、SDN |
| 存储 | 查看存储及其内容，上传镜像、浏览备份 |
| 任务 | 查看操作是否完成，打开详细日志 |

## 数据刷新

资源和状态会定期刷新。页面转入后台时会暂停部分轮询，回到前台后继续更新，因此后台页面不是实时监控告警系统。

操作返回任务后，以任务最终状态为准。页面状态尚未更新时，先看任务日志，避免重复提交同一个操作。
