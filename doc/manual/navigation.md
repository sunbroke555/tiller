# 导航与资源概览

概览把节点、虚拟机和容器集中显示。先找到资源，再进入详情页执行操作，可以减少在不同节点间来回切换。

## 电脑上的入口

左侧主导航包含概览、数据中心、资源池、存储、任务和 Shell；下面的资源树可以直接定位节点及其资源。

点击资源名称进入详情。详情页中的标签会按对象类型变化：虚拟机有硬件和 Cloud-Init，容器有资源、网络和 DNS，节点有网络、磁盘和系统设置等。

## 手机上的入口

底部悬浮导航提供「资源 / 存储 / 任务 / Shell」，搜索按钮打开命令面板。详情页的主要操作放在底部操作栏；较多的操作会收进菜单。

横向标签栏可以滑动。打开编辑表单后，先检查标题中的资源名称，保存前核对目标。账户菜单中可进入数据中心、外观与偏好，以及这份使用文档。

## 搜索与命令面板

点击搜索，或在电脑上按 `Ctrl + K` / `⌘ + K`。命令面板可用于搜索资源、跳转页面，以及执行当前可用的资源操作。

搜索结果中的操作会使用当前账号的权限。遇到删除、停止等确认窗口时，检查具体对象后再继续。

## 概览与数据中心的区别

| 入口 | 适合做什么 |
| --- | --- |
| 概览 / 资源 | 找节点和客户机，查看运行状态与资源使用 |
| 资源池 | 按管理员划分的资源集合浏览客户机 |
| 数据中心 | 管理集群级配置，如权限、存储定义、计划备份、HA、SDN |
| 存储 | 查看存储及其内容，上传镜像、浏览备份 |
| 任务 | 查看操作是否完成，打开详细日志 |

## 数据刷新

资源和状态会定期刷新。页面转入后台时会暂停部分轮询，回到前台后继续更新，因此后台页面不是实时监控告警系统。

操作返回任务后，以任务最终状态为准。页面状态尚未更新时，先看任务日志，避免重复提交同一个操作。
