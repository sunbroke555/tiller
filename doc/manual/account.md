# 账户与权限

Tiller 使用 PVE 的账号和权限。某个按钮不可见、禁用或返回权限错误时，应检查 PVE 授权，不能通过换一个 Tiller 页面绕过权限。

## 管理自己的账户

打开账户菜单，进入「账户与安全」，可查看当前账户并使用界面提供的密码与两步验证管理功能。认证域不同，可用操作也可能不同。

启用两步验证后，妥善保存恢复码，并确认可以正常登录。安全密钥或通行密钥需要兼容的浏览器、HTTPS 地址，以及相符的 WebAuthn 设置。

## 管理用户和授权

具有管理权限的账号，可在「数据中心 → 权限」管理用户、组、角色、认证域、API Token 等。

PVE 授权由三部分共同决定：

- **对象**：授予某个用户或组。
- **路径**：作用于哪些资源，例如某台客户机、存储或资源池。
- **角色**：允许执行哪些操作；传播设置决定是否延伸到下级路径。

查看有效权限比单看用户所属组更可靠。同一账号在不同资源上可能有不同能力。

## API Token

API Token 用于程序调用接口。创建后按界面提示保存令牌密钥，避免把它写进公开文档、截图或日志。

Token 的权限还受其用户权限和权限分离设置影响。网页登录使用账号登录流程，不需要为了使用 Tiller 额外创建 API Token。

## 修改权限之后

如果权限已经调整而界面仍显示旧状态，可刷新页面或重新登录。出现 `403` 时检查目标资源的有效权限；出现 `401` 时先重新登录，详见[常见问题](../guide/troubleshooting.md)。
