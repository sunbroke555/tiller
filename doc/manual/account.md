# 账户与权限

Tiller 使用独立的单管理员账户登录，PVE 实例使用各自的账号密码或 API Token 连接。

## Tiller 管理员

第一次打开时设置用户名和密码。登录后通过账户菜单中的「管理员账户」，修改密码、退出登录。修改密码需验证当前密码，成功后所有设备会话失效。

管理员可以维护所有实例连接。Tiller 当前没有多用户、按实例授权或本地两步验证功能。

## PVE 权限

连接时使用的 PVE 用户或 API Token 决定每个实例可读取和操作哪些资源。添加连接不等于获得 PVE 的全部权限；权限不足时按钮可能不可见、禁用或由 PVE 返回拒绝。

在 PVE 的「数据中心 → 权限」创建专用用户和 API Token，并授予需要的资源范围。启用权限分离时，Token 的有效权限是用户权限和 Token 权限的交集。只需要监控时授予读取权限，需要管理客户机时再增加相应权限。

账号密码连接按实际 PVE 身份显示权限，例如 `root@pam`；Tiller 管理员身份不等于 PVE root。部分接口不支持 Token，可改用有权限的 PVE 账号密码连接，或在 PVE 官方界面完成。要求密码确认时填写的是 PVE 账户密码。

## PVE 密码的保存与更新

PVE 密码加密保存在服务端，不会回显到浏览器；后台维护登录票据，重启后会重新登录 PVE。修改 PVE 密码后，需要同步更新 Tiller 中的实例连接。Tiller 的「修改密码」只修改 Tiller 管理员密码，不会修改 PVE 密码。启用了 PVE 两步验证的账户请使用 API Token。

## Token 的保存与撤销

Token Secret 创建时只显示一次。在 Tiller 保存后会加密存储，不会再次显示给浏览器。修改连接时留空可保留原密钥，但修改地址、证书或 Token ID 时必须重新提供密钥。

在 PVE 撤销 Token 会使对应连接失效，不影响 Tiller 管理员登录或其他实例。删除 Tiller 连接不会自动撤销 PVE Token，需要时请在 PVE 中另行删除。
