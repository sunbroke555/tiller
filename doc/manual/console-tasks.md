# 控制台与任务日志

控制台让你直接操作客户机或节点；任务日志用来确认一次管理操作是否完成。两者都通过当前 Tiller 实例连接 PVE。

## 打开控制台

在客户机详情中选择控制台。虚拟机通常使用图形控制台，容器和节点 Shell 使用终端；串口与 SPICE 等方式取决于客户机配置和界面提供的入口。

如果使用 SPICE 下载 `.vv` 文件，需要在设备上安装兼容的客户端，浏览器本身不会直接显示 SPICE 桌面。

## 手机上输入

点击终端输入区域唤起键盘。需要发送特殊按键时使用控制台提供的按键工具；手机系统可能拦截某些组合键，浏览器键盘不一定与实体键盘完全相同。

节点 Shell 中输入的命令直接在对应 PVE 节点执行。执行前检查节点名称，尤其是重启、磁盘和网络命令。

## 控制台断开

先确认客户机仍在运行，再尝试重新连接。若普通页面可用而控制台持续断开，检查 Tiller 前面的反向代理是否允许 WebSocket，以及是否设置了过短的连接超时。

从 HTTP 切换到 HTTPS 或更换域名后，重新打开完整页面再连接。不要把旧页面的连接失败直接当成客户机故障。

## 跟踪长任务

备份、恢复、迁移等操作通常先返回一个任务。底部提示或任务栏可打开实时日志，也可以进入「任务」页按条件查找。

1. 核对任务类型、节点、客户机和开始时间。
2. 查看是否仍在运行。
3. 任务结束后查看最终状态；失败时阅读日志末尾，并向前寻找具体错误。

任务标识 `UPID` 用于定位一次 PVE 操作。需要求助时可以提供任务时间、对象、错误信息和相关日志，隐藏敏感信息。

## 停止任务与下载日志

支持停止的任务会提供相应入口。停止不会自动撤销任务已完成的修改，确认停止后仍需检查资源状态。

日志下载可用于留档或排查问题。集群日志、节点系统日志与任务日志用途不同：任务日志解释单次操作，系统日志反映节点服务，集群日志反映集群事件。
