# 外观与手机使用

从账户菜单打开「外观与偏好」，或使用电脑侧栏的「外观」入口。设置保存在当前浏览器，每台设备可单独选择。

## 主题与质感

| 设置 | 效果 |
| --- | --- |
| 暗色玻璃 | 深色背景与半透明表面 |
| 浅色玻璃 | 浅色背景与半透明表面 |
| 纸质 | 暖色实底，使用纸张风格的排版 |
| 跟随系统 | 随系统在暗色和浅色之间切换 |
| 强调色 | 调整玻璃主题的强调颜色；纸质主题使用固定配色 |
| 玻璃质感 | 关闭后使用实色表面，适合性能较弱的手机 |
| 列表密度 | 在舒适与紧凑之间切换 |

这份独立文档使用自己的深浅色切换，不改变管理界面的主题偏好。

## 添加到主屏幕

使用设备信任的 HTTPS 地址打开 Tiller，再通过浏览器的安装入口或「添加到主屏幕」操作安装。入口名称与是否显示安装提示取决于浏览器。

安装后会有独立图标和接近应用的窗口。管理资源、登录和查看实时状态仍需要网络；离线外壳不代表可以离线操作 PVE。

## 小屏操作

底部导航切换主要页面，详情页底部操作栏提供常用动作。横向标签栏可以左右滑动，较长的表单会在弹层里滚动。

在控制台输入时，使用页面的特殊按键工具。切换到其他应用后，手机可能暂停网络连接，回到 Tiller 后检查连接是否已经恢复。

## 更新界面

更新 Tiller 后，页面会获取新版资源。若页面长期停留在旧版本，先刷新或关闭后重新打开；仍异常时再按[排查说明](../guide/troubleshooting.md#更新后界面异常)处理浏览器缓存。
